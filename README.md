# Unlock Reminder Visual Enhancement

> **Compatible with Rep / Rep+**

This is an unofficial visual enhancement of **Unlock Reminder**.

This mod is based on **Unlock Reminder** by **modelixxx** and uses completion mark sprites from **Cooler Completion Marks [REP+]** by **Eden**. The original functionality, code, and assets belong to their respective creators. This version focuses on improving the visuals while preserving the original features.

The goal of this edit is simple: keep the original functionality while making the unlock sheet cleaner, more intuitive, and more aesthetically pleasing. All gameplay functionality remains the same. The only changes are visual improvements that make it easier to identify completion marks at a glance.

## Features

- ✅ Improved completion icons.
- ✅ Better overall visual consistency.
- ✅ Preserves the original functionality of Unlock Reminder.
